# brand-assets

브랜드별 **공개용** 이미지 (웹 앱 탭 아이콘 등). 브라우저가 로그인 없이 가져가야 하는 파일만 둔다.
코드 · 설정 · 문서는 private 저장소 `ecommerce-automation`에 둔다.

| 브랜드 | 파일 | 용도 | Raw URL |
|---|---|---|---|
| Dermafirm | `dermafirm/favicon.png` (124×124 PNG, 투명 배경) | 웹 앱 탭 아이콘 (`APP_FAVICON_URL`) | https://raw.githubusercontent.com/Yeshinino/brand-assets/main/dermafirm/favicon.png |

- 새 브랜드: `<브랜드>/favicon.png` 추가 → 이 표에 한 줄 추가.
- 파일을 바꿀 때 이름은 그대로 두면 URL이 바뀌지 않는다 (브라우저 캐시 때문에 반영이 늦을 수 있음).
